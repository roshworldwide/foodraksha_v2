# Fonts embedded into generated PDFs

`Inter-Regular.ttf` and `Inter-Bold.ttf`, from Google Fonts (Inter v20).

Licensed under the SIL Open Font License 1.1, which permits embedding in
documents. They are committed rather than fetched at build time so a
generated annexure looks identical on every machine, forever, with no
network dependency.

Source: https://fonts.google.com/specimen/Inter
